使用方法
1. 解压 ZIP。
2. 打开 ClassIn 客户端，并登录需要导出资源的账号。
3. 打开 ClassInExporter，点击“获取资源”。
4. 在左侧选择课程 / 云盘，选择要获取的对应资源。
5. 点击“下载已选”批量下载。

默认导出位置在 exports 文件夹。
点击“设置”可更改安装目录，以及获取 / 下载线程数。
切换 ClassIn 账号后请重新扫描资源。
